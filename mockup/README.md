# ALTUZ · Mockup de prendas (Drop 001)

Visor 3D generado por código a partir del Tech Pack v1.3. 1 unidad = 1 cm (escala real 1:1).

- Camiseta negra (T01), camiseta blanca (T02) y short (S01), tallas S · M · L · XL con las medidas de TP-03 y TP-07.
- Geometría procedural (SDF + surface nets), cuello/mangas/bajos abiertos con ribetes, costuras TPU, perforación trasera,
  reflectantes A y ALTUZ, slogan, etiquetas con número, bolsillo con cremallera, cordón, abertura lateral, etc.
- Botones: vistas, detalles, regla en cm, cotas del tech pack, modo noche (reflectante), malla, turntable,
  calidad alta, **exportar GLB** (en metros, listo para Blender) y PNG.

Abrir `mockup/index.html` con cualquier servidor estático (en Vercel: `/mockup/`).
Nota: el GLB lleva geometría, colores y materiales PBR; la textura de punto procedural solo existe en el visor.
